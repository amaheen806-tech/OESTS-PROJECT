# Orphan Educational Sponsorship and Tracking System (OESTS)

Welcome to the OESTS project! This project connects verified orphans, partner schools, and donors on one platform — ensuring transparent education sponsorship.

## 🚀 Live Demo Links

- **Frontend (Live Website):** [https://oests.vercel.app](https://oests.vercel.app)
- **Backend API (Django):** [https://oests-project.onrender.com/api](https://oests-project.onrender.com/api)
- **Admin Panel:** [https://oests-project.onrender.com/admin/](https://oests-project.onrender.com/admin/)

## 📂 Project Structure

- `orphan-sponsorship-frontend/`: React + Vite frontend application.
- `orphan-sponsorship-backend/`: Django REST Framework backend application.

## ⚙️ Technologies Used

- **Frontend:** React, Vite, TailwindCSS
- **Backend:** Django, Django REST Framework, PostgreSQL
- **Media Storage:** Cloudinary
- **Deployment:** Vercel (Frontend), Render (Backend)
